# Architecture Decision Records

```markdown
# NNNN. Title

- Status: accepted | superseded by NNNN
- Problem: P# (docs/problems.md)

## Context
What forces this decision.

## Options considered
Each option with its pros and cons.

## Decision
What was chosen and why.

## Consequences
What this costs, and what would make us revisit it.
```
